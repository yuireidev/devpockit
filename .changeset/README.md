# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, our build tool that manages multi-package repos. You might not need this folder if your project isn't a multi-package repo.

**What are changesets?**

Changesets are a tool that helps us write release notes and version our packages. When you make a change, you can add a changeset to describe it. Then, when we want to make a release, we can use the changesets to generate the release notes and version our packages.

**How do I add a changeset?**

1. Run `pnpm changeset`
2. Follow the prompts to describe your change
3. A new file will be created in this folder
4. Commit the file with your changes

**What do I do when I want to release?**

1. Run `pnpm changeset:version` to version the packages
2. Run `pnpm changeset publish` to publish the packages
